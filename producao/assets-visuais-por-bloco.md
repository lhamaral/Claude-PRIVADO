# Assets visuais por bloco — Checklist de grafismo

Cada episódio precisa de textos na tela (motion graphics) que apareçam sincronizados com a narração. Aqui está o que você vai precisar preparar **antes** de cada gravação.

---

## BLOCO 1 · Optar pelo regime

**Tema:** Decisão de regime (Simples vs. regular)  
**Visual principal:** Diagrama de prazos (setembro → janeiro → junho → março)  
**Cores:** Urgência moderada (amarelo/laranja para datas críticas)

```

[seta]

[seta]

[seta]

```
**Assets:** Timeline visual, ícones de decisão

### E02 · O QUE SABER

## Padrão de design recomendado

### Paleta de cores
- **Urgência:** Laranja (datas, prazos)
- **Benefício:** Verde (ganho, desconto)
- **Neutro:** Azul/Cinza (informação pura)
- **Atenção:** Vermelho (risco, perda)
- **Informação:** Branco/Preto (texto)

### Tipografia
- **Títulos:** Sem-serifa, 48-72pt, peso bold
- **Subtítulos:** Sem-serifa, 32-48pt, peso medium
- **Corpo:** Sem-serifa, 20-28pt, peso regular
- **Números:** Sem-serifa, 56-80pt, peso bold (destacados)

### Duração de cada texto na tela
- Títulos principais: 3-5 segundos
- Transições: 1-2 segundos
- Números: 8-15 segundos (tempo para ler)
- Checklist final: 5-8 segundos

### Efeitos recomendados
- Fade in/out (não corte seco)
- Slide de esquerda para direita (para sequências)
- Zoom suave para números importantes
- Pausa 0.5s entre textos (respiro visual)

## Checklist por episódio antes de gravar

Para **cada** vídeo:
- [ ] Assets visuais foram criados/aprovados
- [ ] Timing de cada texto foi cronometrado
- [ ] Cores estão alinhadas com palet de cores
- [ ] Números aparecem em fonte grande o suficiente (legível em celular)
- [ ] Transições não competem com voz (fala pausada nesses pontos)
